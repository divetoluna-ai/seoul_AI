# 반려견 정보 관리

내 계정 → 반려견 맞춤 조건 관리에서 이름과 선호 산책 시간을 등록·수정·삭제할 수 있습니다.
이름 공개·비공개 전환과 공개 프로필 링크를 제거했습니다. 이전 저장 파일의 publicProfile 필드는 호환성을 위해 읽을 때 무시하고 다시 저장하지 않습니다. 공개 조회·공개 설정 API는 제거되어 기존 공개 링크로 이름을 조회할 수 없습니다.

삭제 버튼을 누르면 대상 반려견을 확인한 뒤 삭제 확인 또는 취소를 선택합니다. DELETE /api/auth/dogs/{id}는 유효한 로그인과 X-Auth-Client: web 헤더를 검사하며 해당 계정이 소유한 반려견만 삭제합니다. 이름·선호 산책 시간은 members.json에서 삭제되고 목록과 추천 조건도 즉시 갱신됩니다. 계정, 다른 반려견, 공유 코스 및 포인트는 삭제하지 않습니다. 저장에 실패하면 오류를 표시하고 기존 정보를 유지합니다.
