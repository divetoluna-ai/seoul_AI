# 포인트 상점

- 진입: 상단 **포인트 상점** 메뉴 또는 `/#shop`
- 환산: **1P = 1원**. 판매가 기준이며 배송비·옵션 추가금은 제외합니다.
- 범위: 상품 조회, 검색, 포인트 가격순 정렬, 보유 포인트 이내 필터, 원본 상품 페이지 연결.
- 실제 주문·배송·포인트 차감 기능은 아직 연결하지 않습니다.
- 보유 포인트는 카카오 계정에 연결된 이웃 프로필의 서버 잔액을 사용합니다. 같은 계정으로 재로그인해도 잔액과 중복 적립 방지 기록을 유지합니다.

## 로그인 및 적립 UI

상점 메뉴·페이지·상품 API는 카카오 로그인 후에만 이용할 수 있습니다. 비로그인 직접 진입은 장소 둘러보기로 이동합니다. 포인트 적립·NFC·적립 내역 및 포인트 프로필 설정은 상점에서만 표시합니다.

지도·코스 공유, 공유 완료 적립, 좋아요, 프로필 수정 및 NFC 적립 요청도 유효한 카카오 로그인 세션이 필요합니다. 커뮤니티 목록과 공유받은 코스 조회는 비로그인 상태에서도 가능합니다. 계정 식별자는 서버 세션에서만 결정하며, 이전 `daeng-community` 쿠키로 로그인이나 포인트 계정을 대신할 수 없습니다.

이전 익명 프로필·코스·포인트 데이터는 삭제하지 않습니다. 계정 소유자를 확인할 수 없는 익명 잔액은 로그인한 계정으로 자동 이전하지 않습니다. 현재 코스 커뮤니티에는 댓글 작성 기능이 없습니다.

인증 쿠키는 HttpOnly·SameSite=Lax 속성을 유지하며 `/api` 경로에서만 사용합니다. 기존 `/api/auth` 쿠키는 유효한 로그인 상태 조회 시 새 경로로 전환하고, 로그아웃 시 두 경로의 쿠키를 모두 만료시킵니다.

## 상품 공급

`GET /api/auth/shop/products`는 https://www.adorable-dog.com/ 메인에 공개된 상품을 읽습니다.
판매가를 해석할 수 없는 항목은 제외하며 상품 ID로 중복을 제거합니다. 원본 상품 링크와 사진 출처를 표시합니다.
1시간 동안 서버 메모리에 보관하고 이후 조회 때 갱신합니다. 실패 시 60초 후 재시도하며 이전 성공 데이터가 있으면 마지막 확인 시각과 지연 표시를 함께 제공합니다.
최초 수집에 실패하면 503을 반환하고 화면에서 재시도 및 쇼핑몰 직접 방문을 제공합니다.
전체 쇼핑몰 재고를 보장하는 목록이 아니며 가격·옵션·품절 여부는 원본 상품 페이지가 최종 기준입니다.
