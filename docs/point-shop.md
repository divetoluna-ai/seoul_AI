# 포인트 상점

- 진입: 상단 **포인트 상점** 메뉴 또는 `/#shop`
- 환산: **1P = 1원**. 판매가 기준이며 배송비·옵션 추가금은 제외합니다.
- 범위: 상품 조회, 검색, 포인트 가격순 정렬, 보유 포인트 이내 필터, 원본 상품 페이지 연결.
- 실제 주문·배송·포인트 차감 기능은 아직 연결하지 않습니다.
- 보유 포인트는 기존 이웃 프로필의 서버 잔액을 사용합니다. 카카오 회원 로그인과 이웃 프로필은 현재 별도입니다.

## 상품 공급

`GET /api/shop/products`는 https://www.adorable-dog.com/ 메인에 공개된 상품을 읽습니다.
판매가를 해석할 수 없는 항목은 제외하며 상품 ID로 중복을 제거합니다. 원본 상품 링크와 사진 출처를 표시합니다.
1시간 동안 서버 메모리에 보관하고 이후 조회 때 갱신합니다. 실패 시 60초 후 재시도하며 이전 성공 데이터가 있으면 마지막 확인 시각과 지연 표시를 함께 제공합니다.
최초 수집에 실패하면 503을 반환하고 화면에서 재시도 및 쇼핑몰 직접 방문을 제공합니다.
전체 쇼핑몰 재고를 보장하는 목록이 아니며 가격·옵션·품절 여부는 원본 상품 페이지가 최종 기준입니다.
